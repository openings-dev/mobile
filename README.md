# Openings Mobile

Private Expo bare-workflow application for Openings on iOS and Android.

## Local development

The first foundation release consumes `@openingshq/core` and `@openingshq/design-tokens` from the sibling local repositories. Build both packages before installing or starting the mobile application.

```sh
npm install
npm run check
npm start
```

The application identifier is `dev.openings.mobile` on both platforms.
