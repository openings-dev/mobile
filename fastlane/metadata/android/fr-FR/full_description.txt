Trouvez des opportunités dans la tech là où les communautés les partagent déjà.

Openings rassemble les offres publiques de dépôts de communautés GitHub dans une expérience ciblée et pensée pour le mobile. Recherchez des postes, affinez les résultats avec des filtres utiles et revenez toujours à la source publique d'origine avant de postuler.

AVEC OPENINGS, VOUS POUVEZ

• Découvrir des emplois tech issus de communautés GitHub publiques
• Filtrer par lieu, mode de travail, niveau, technologie, type de contrat, date, salaire et communauté
• Consulter les détails, les informations sur la source et le contexte de publication
• Enregistrer les opportunités intéressantes localement sur votre appareil
• Explorer les communautés actives et les auteurs liés aux publications
• Utiliser l'app en français, anglais, portugais, espagnol, italien ou allemand
• Choisir le thème clair, sombre ou système

Openings est un outil de découverte. Il ne reçoit pas de candidatures, ne vérifie pas les employeurs et ne garantit pas qu'une offre soit toujours disponible. Chaque opportunité renvoie vers sa source publique d'origine pour vérifier les détails et poursuivre sur celle-ci.

Aucun compte n'est requis. Les emplois enregistrés et les préférences restent sur votre appareil.
