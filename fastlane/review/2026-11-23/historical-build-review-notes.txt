Response to Guideline 2.1 - information for review

1. Demonstration: Attached Openings-0.1.1-1-iPhone16Pro.mp4 was recorded on a physical iPhone 16 Pro running iOS 27.2.1, from launching the app. It shows loading jobs, opening a listing, saving it, visiting its original GitHub source, returning to the app, and browsing communities and authors. A personal notification before app launch is concealed for privacy; app interactions are unchanged. The recording is resized and has no audio.

2. Purpose and audience: Openings helps people discover technology jobs published in public GitHub community repositories. It organizes listings, filters, communities and authors, and lets readers keep saved jobs on their own device. It does not verify employers, guarantee that a role is available, rank candidate suitability, handle job applications or make hiring decisions.

3. Review access: No account, registration, login, credentials, payment or sample files are required. Internet is required to fetch the current public catalog. On Jobs, use search or filters, open a job and save it, or open the original listing. The menu opens Communities and Authors. Saved jobs, viewed state, language and appearance preferences remain local. There is no paid content or app account to delete. Users cannot post jobs, comments or messages in this app. A job's Actions menu includes Report a problem, which opens a prefilled issue in the project's GitHub repository; submitting that external report requires a GitHub account. The app does not implement author blocking.

4. External services: The catalog is generated by the Openings data pipeline and fetched as public JSON snapshots from raw.githubusercontent.com/openings-dev/data-pipeline. Original job links open GitHub or the system browser. Firebase Remote Config handles version configuration; Firebase Crashlytics and Sentry support diagnostics. Mixpanel analytics is optional, and OneSignal push notifications are opt-in. The app does not send saved jobs or searches as analytics properties. There is no runtime AI service, authentication backend or payment service. Sharing uses the operating system share sheet.

5. Regions: The same features are offered across supported storefronts. Available jobs depend on the source communities and the user's selected filters, not geographic feature restrictions. The interface supports English, Portuguese, Spanish, Italian, French and German; original listing text stays in its source language. Mainland China is excluded from distribution.

6. Content and authorization: Openings is a discovery interface, not a regulated employment agency or financial service. Listings originate in identified third-party GitHub repositories, with author/community attribution and links back to each original listing. We do not claim affiliation with GitHub, listed employers or communities. Content-rights documentation is being checked before resubmission.
